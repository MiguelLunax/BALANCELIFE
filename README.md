# BalanceLife

Aplicación para gestionar hábitos saludables y promover un estilo de vida equilibrado.

## Instalación

1. Clonar el repositorio
2. Ejecutar `npm install` para instalar dependencias
3. Configurar variables de entorno en el archivo `.env`
4. Ejecutar `npm run dev` para iniciar en modo desarrollo

## Estructura del proyecto

El proyecto sigue una arquitectura modular con patrón MVC para cada funcionalidad.
